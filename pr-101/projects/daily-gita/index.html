Daily Gita

Verse reader that ships its database with the app. No server.

React Native · Expo · expo-sqlite · Nativewind · Scrapy

Source ↗

The problem

A daily verse reader should not need accounts, a backend, or connectivity.

How it works

Scrapy spiders crawl English, Hindi and Telugu verse pages into a trilingual CSV, compiled into a SQLite database bundled as a 2.8 MB app asset and read through SQLiteProvider — zero network calls. Around it: a drawer shell, settings, terms and privacy screens.

Limits

UI prototype. The dataset and bundling are done; the reading loop is not. The home screen renders placeholder text, getVerse() ignores its arguments, the language picker is local state that is never persisted, and the history table has no writer. The scrape also needs deduping: 701 rows hold about 590 distinct chapter and verse pairs.
