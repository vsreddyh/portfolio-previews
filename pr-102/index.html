About

I'm a software engineer in Hyderabad working across the stack — React and Node on the frontend-facing side, Python/Go/FastAPI and Postgres-flavoured infrastructure underneath, with a growing obsession for agentic AI that actually runs reliably outside a demo.

My bias is toward boring operations: Docker Compose over bespoke platforms, nightly batch jobs over always-on spend, SQLite and Postgres before exotic stores. Most of my side projects are experiments in how much can run unattended — retention jobs, cron syncs, self-hosted search — without me babysitting them.

Currently a Software Engineer at 5th Bridge Data Technologies, and a B.Tech CSE student at KMIT (2022–2026). When I'm not shipping, I'm usually automating something in my own setup that didn't need automating.
